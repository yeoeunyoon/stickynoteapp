# StickyNotes App

A simple web application where users can add, edit, and delete sticky notes.


## How to Run This Project Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/your-repo.git
   cd your-repo
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser and go to:**
   ```
   http://localhost:5173
   ```
   (The port number may vary depending on your setup. Check the terminal output.)

---

**Note:**  
This project uses a development server for local testing.  
To view the app, you must run the development server as shown above.

If you want to deploy the app as a static website, please build the project first:
```bash
npm run build
```
and then serve the contents of the `dist` folder using a static server.
